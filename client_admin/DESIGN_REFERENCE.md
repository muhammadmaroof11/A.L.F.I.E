## Ambient Effect (Background)

The cinematic style relies on slow-moving blurred ambient lights behind the frosted glass UI.

```css
body::before, body::after {
  content: '';
  position: fixed;
  border-radius: 50%;
  filter: blur(80px);
  pointer-events: none;
  z-index: 0;
  animation: blob-drift 20s ease-in-out infinite alternate;
}
body::before {
  width: 600px; height: 600px;
  background: radial-gradient(circle, rgba(59,130,246,0.07) 0%, transparent 70%);
  top: -200px; left: -100px;
}
body::after {
  width: 500px; height: 500px;
  background: radial-gradient(circle, rgba(94,106,210,0.06) 0%, transparent 70%);
  bottom: -200px; right: -100px;
  animation-delay: -10s;
}
@keyframes blob-drift {
  0%   { transform: translate(0, 0) scale(1); }
  100% { transform: translate(40px, 30px) scale(1.08); }
}
```

## Design vs Super Admin
- **Super Admin**: Fira Code heavy, tight metrics, terminal-style logs, sharp `#020617` background.
- **Client Admin**: Inter font for approachability, `Modern Dark Cinema` glassmorphism, floating cards with `rgba(255,255,255,0.08)` borders, atmospheric blurred color blobs in background. Higher contrast on call-to-actions (green/blue).
