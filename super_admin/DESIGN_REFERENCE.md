## Motion Spec (Tailwind + GSAP)

Use stagger-grid entrance on dashboard cards:
```js
// On page mount
gsap.from('.stat-card', {
  opacity: 0, scale: 0.92, y: 16,
  duration: 0.4, stagger: { each: 0.06, from: 'start', grid: 'auto' },
  ease: 'back.out(1.4)'
});
```

All interactive elements: `transition-all duration-150` minimum.
Page transitions: `opacity-0 translate-y-1.5` → `opacity-100 translate-y-0` over `200ms ease-out`.
