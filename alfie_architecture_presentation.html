Fault-Tolerant Operations

Live Hot Transfer & Line-Busy Fallback Mechanism

How A.L.F.I.E guarantees zero dropped opportunities during peak call volume and department transfers.

1. Transfer Request & Warm Context Buffer HOT TRANSFER

When caller requests transfer (e.g. "Connect me to Senior Partner"), A.L.F.I.E buffers the conversation summary and lead qualification in Redis transfer_buffer:{call_id}.

  • LiveKit SIP REFERDirect Extension Transfer
  • Context HandoffScreen-Pop JSON
2. Line-Busy / Unavailable Detection FALLBACK DETECTION

If the extension returns 486 Busy Here, 408 Request Timeout, or after-hours status, the agent immediately re-engages the caller without hanging up.

  • SIP Response Code486 / 480 / 408
  • Agent Verbal Re-engagement< 400ms Turnaround
3. Priority Callback Ticket Booking SCHEDULE CALLBACK

The AI agent proactively asks for preferred callback time, creates an entry in PostgreSQL alfie_callbacks, updates CRM lead record, and triggers an instant Slack / CRM webhook notification.

  • Tool Executedschedule_callback()
  • Webhook Triggeredclient_callback_scheduled
